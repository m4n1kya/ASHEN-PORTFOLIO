# Manikya N. - Software Engineering Portfolio

Welcome to my personal software engineering portfolio repository! 

This repository contains the source code for my interactive, 3D web portfolio built to showcase my technical skills, projects, and professional experience.

## Tech Stack
- **React.js** - Frontend UI library
- **Three.js & React Three Fiber** - 3D models and rendering
- **Tailwind CSS** - Styling and responsive design
- **GSAP** - Complex web animations
- **Vite** - Build tool

## Features
- **Interactive 3D Elements:** Custom 3D computer setup and floating tech stack models.
- **Dynamic Animations:** Smooth scroll-triggered animations powered by GSAP.
- **Fully Responsive:** Optimized for both desktop and mobile viewing.
- **Contact Integration:** Direct messaging via EmailJS integration.

## Setup Instructions
To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/m4n1kya/ASHEN-PORTFOLIO.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
